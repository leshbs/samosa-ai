# 0007. Naik ke React 19

- **Status:** Accepted. Pemicunya (react-pdf di server) dihapus di ADR-0013;
  react-pdf kembali di ADR-0014, kali ini hanya di browser. React 19 tetap,
  karena Next 15 memang dipasangkan dengannya.
- **Date:** 2026-09-22

## Context

Export PDF (ADR-0004, `@react-pdf/renderer`) render dengan benar di test Node
dan gagal 500 di route handler Next dengan `Minified React error #31` —
"Objects are not valid as a React child".

Diagnosisnya diukur, bukan ditebak. Sebuah route diagnostik melaporkan:

- Di server layer Next, `react` **selalu** resolve ke React bundled milik Next,
  `19.2.0-canary`, bahkan lewat `createRequire` dari root proyek. Elemen yang
  dibuat JSX ber-`$$typeof: Symbol(react.transitional.element)`.
- Proyek sendiri masih React 18.3.1, jadi pnpm menaut
  `@react-pdf/reconciler@2.0.0_react@18.3.1`. Reconciler itu memilih build-nya
  saat runtime dari `React.version`, dan build React 18 hanya mengenali
  `Symbol(react.element)`.

Jadi elemen React 19 diserahkan ke reconciler React 18, yang melihatnya sebagai
objek biasa dan melempar #31. Menambah `@react-pdf/renderer` ke
`serverExternalPackages` tidak menolong, karena Next tetap mengarahkan `react`
ke bundle miliknya.

## Decision

Naikkan `react` dan `react-dom` ke ^19 (plus `@types/*`). Next 15 memang
dipasangkan dengan React 19; proyek yang tertinggal di 18 adalah anomalinya,
dan server layer sudah menjalankan React 19 sejak awal.

`serverExternalPackages` **tidak** perlu entry baru — sudah diuji tanpa itu dan
PDF tetap ter-render.

## Consequences

- (+) Export PDF jalan di runtime yang sebenarnya, bukan cuma di test.
- (+) Versi React di client dan server layer akhirnya sama.
- (−) Upgrade major yang menyentuh seluruh app. Diverifikasi: `pnpm check`
  bersih, 159 test lolos, `pnpm build` sukses, dan seluruh halaman diklik di
  browser (5 chart ter-render, filter explorer jalan, dialog terbuka, nol error
  di console).

## Alternatives considered

- **Tetap di React 18, ganti library PDF** (pdfmake / pdfkit langsung) —
  menghindari React sepenuhnya, tapi membuang ADR-0004 yang baru diterima dan
  menulis ulang seluruh layout demi menghindari upgrade yang memang seharusnya
  dilakukan.
- **Render PDF di proses terpisah** — menyelesaikan masalah versi dengan
  menambah satu deployment unit. Terlalu mahal untuk satu tombol export.
